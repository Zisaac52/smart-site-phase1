# 智慧工地 AI 视觉安全闭环管理系统 — 本地运行指南

## 环境要求

| 组件 | 版本 | 用途 |
|------|------|------|
| JDK | 17+ | 后端编译运行 |
| Maven | 3.6+ | 后端构建 |
| MySQL | 8.x | 数据库 |
| Redis | 6+ | 缓存/Token |
| Node.js | 16+ | 前端编译运行 |

## 1. 克隆项目

```bash
git clone https://github.com/king-buming/RuoYi-Vue-springboot3.git
cd RuoYi-Vue-springboot3/RuoYi-Vue-springboot3   # 注意：真正的代码在这层嵌套目录
```

## 2. 配置数据库

### 2.1 启动 MySQL，创建数据库和账号

```bash
mysql -u root -p
```

```sql
CREATE DATABASE `ry-vue` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'ruoyi'@'localhost' IDENTIFIED BY 'Ruoyi@2026';
GRANT ALL PRIVILEGES ON `ry-vue`.* TO 'ruoyi'@'localhost';
FLUSH PRIVILEGES;
```

> 如果你用其他账号/密码，请修改 `ruoyi-admin/src/main/resources/application-druid.yml` 中的 `username` 和 `password`。

### 2.2 导入系统基础表 + 业务表

```bash
# 系统核心表（若依原生）
mysql -u ruoyi -pRuoyi@2026 ry-vue < sql/ry_20260417.sql
mysql -u ruoyi -pRuoyi@2026 ry-vue < sql/quartz.sql

# 业务模块（按文件名顺序执行）
mysql -u ruoyi -pRuoyi@2026 ry-vue < sql/updates/20260601_0900_worker_module.sql
mysql -u ruoyi -pRuoyi@2026 ry-vue < sql/updates/20260601_0930_worker_role_menu.sql
mysql -u ruoyi -pRuoyi@2026 ry-vue < sql/updates/20260601_1000_worker_cert_menu.sql
mysql -u ruoyi -pRuoyi@2026 ry-vue < sql/updates/20260601_1030_worker_face_menu.sql
mysql -u ruoyi -pRuoyi@2026 ry-vue < sql/updates/20260601_1100_worker_audit_menu.sql
mysql -u ruoyi -pRuoyi@2026 ry-vue < sql/updates/20260602_1200_worker_checkin_menu.sql
```

## 3. 配置 Redis

确保 Redis 已启动：

```bash
redis-server
# 或
sudo service redis-server start
```

默认配置连接 `localhost:6379`，无需密码。

## 4. 编译并启动后端

```bash
mvn clean install -DskipTests
nohup java -jar ruoyi-admin/target/ruoyi-admin.jar > backend.log 2>&1 &
```

后端默认运行在 **8080** 端口。

## 5. 编译并启动前端（后台管理）

```bash
cd ruoyi-ui
npm install
npm run dev
```

后台管理默认运行在 **80** 端口。

> 如果 80 端口被占用，用 `port=8081 npm run dev` 改用 8081。

## 6. 访问系统

| 入口 | 地址 | 账号 |
|------|------|------|
| 后台管理 | http://localhost | admin / admin123 |
| 手机端 H5 | http://localhost:8081/mobile.html | 手机号 + 身份证后6位（需先录入人员） |

## 7. 快速录入测试数据

手机端登录前需要先在后台「人员管理 → 人员档案」里新增人员：

1. 用 admin/admin123 登录后台
2. 人员管理 → 人员档案 → 新增
3. 填写姓名、手机号、身份证号（必填）
4. 保存后，该人员即可在手机端用「手机号 + 身份证后6位」登录

## 手机端功能

手机端 H5 无需编译，浏览器直接打开即可。功能包括：

- 登录（手机号+身份证后6位）
- 签到 / 签退（含拍照上传）
- 打卡记录查询
- 个人资料查看
- 身份证上传（人像面 + 国徽面）
- 资质证件上传（多图）
- 人脸上传

## 常见问题

**Q: 前端启动后页面空白？**
A: 确认后端 8080 端口已启动，前端 dev server 会自动代理 API 到后端。

**Q: 登录报"认证失败"？**
A: 确认 Redis 已启动。

**Q: 手机端登录报"手机号或密码不正确"？**
A: 检查该人员是否已在后台录入、是否被归档/禁用。
